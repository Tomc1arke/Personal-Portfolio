Smart Blur

Smart Blur is a web-based image privacy tool that automatically detects sensitive information, such as human faces and vehicle license plates, using YOLOv8 object detection models. Users can review, resize, move, or remove the detected bounding boxes before confirming them. OpenCV is then used to blur the selected regions, and the anonymised image can be downloaded through the web application.

Geosig

GeoSig is a security-focused application designed to combat QR code fraud using geolocation verification. It consists of an admin website for registering QR codes with location data and a mobile app for scanning them. When a code is scanned, the system checks it against stored data and its expected location before directing the user to the verified website.

Symrise Flavour App

Symrise Flavour Creation App is a full-stack application designed to help customers and flavorists collaborate on custom toothpaste flavors. Customers can create flavors from a list of ingredients, set ingredient percentages, submit them for review, and revise rejected versions. Flavorists can review submissions, leave comments, and approve or reject flavors through a role-based dashboard.
